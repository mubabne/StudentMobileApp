# Оюутны төлөвлөгч

Хичээлийн хуваарь, даалгаврын хугацаа, лекцийн тэмдэглэлийг нэг дор
удирдах Flutter апп.

## Ажиллуулах

```sh
flutter pub get
flutter run
```

Demo нэвтрэх мэдээлэл талбар дээр бэлэн байна. Шинэ бүртгэлийн demo
баталгаажуулах код: `123456`.

Microsoft authentication хэсэг нь UI demo. Бодитоор холбоход Azure app-ийн
client ID болон сургуулийн tenant тохиргоо шаардлагатай.
